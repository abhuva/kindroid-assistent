# About these notes

This is a public working journal for a local Kindroid archive and analysis tool.
It documents the process as well as the outcomes: representation choices,
implementation experiments, performance checks and interpretive limits.

The journal is maintained by **abhuva**. The
[project repository](https://github.com/abhuva/kindroid-assistent) contains the
application; the site's publication source lives on its `docs-site` branch.

This is an independent project, not an official Kindroid product or a claim to
provide psychological assessment. The scope is tooling and exploratory methods.

The site is built with [Zensical](https://zensical.org/) and hosted on GitHub Pages.
It uses local theme assets and system fonts, with no added analytics or comment
service. GitHub operates the hosting platform under its own privacy policies.

See the [publication policy](publication-policy.md) for the boundary between public
notes and the underlying private material.
